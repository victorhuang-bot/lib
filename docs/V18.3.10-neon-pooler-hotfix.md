# V18.3.10 Neon Pooler Hotfix

Render deploy log 顯示 Neon pooler 拒絕：

`unsupported startup parameter in options: statement_timeout`

因此 V18.3.10：
1. 不再把 statement_timeout 放在 PostgreSQL startup options。
2. 連線取得後再嘗試設定 statement_timeout。
3. 系統啟動連線增加 3 次重試。
4. 其餘 V18.3.9 功能全部保留。

Render Environment 的 `DATABASE_URL` 不需要更改，仍可繼續使用 Neon 的 `-pooler` connection string。
