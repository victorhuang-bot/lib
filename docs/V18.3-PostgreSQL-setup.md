# V18.3 PostgreSQL 建置步驟

建議免費方案：Neon PostgreSQL。Render Free Web Service 可透過 HTTPS/一般資料庫連線存取外部 PostgreSQL。

1. 建立 Neon 帳號與 Project。
2. 在 Neon Project 的 Connect / Connection Details 複製 PostgreSQL connection string。
3. 確認連線字串包含 `sslmode=require`（若 Neon 提供的字串已包含就不要重複）。
4. Render → library-logistics-demo → Environment → Add Environment Variable。
5. Key：`DATABASE_URL`
6. Value：貼上完整 PostgreSQL connection string。
7. Save Changes，等待 Render 重新部署。
8. 第一次啟動會自動建立資料表、路線1-6與74個正式分館。
9. 登入後先檢查「分館管理」與「路線 / 每日指派」。
10. 在今日司機下拉選單選「支援司機1」時，系統會要求再次確認才送出指派。

注意：第一次切換 PostgreSQL 是新的空資料庫；V18.2 原 SQLite 的歷史測試資料不會自動搬過去。
